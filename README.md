# 洞察报告交互原型

桌面网页单文件交互原型，包含模板管理、任务澄清、图表与分析摘要占位符、报告生成演示、编辑和数据质量校验。

访问地址：https://icapk.github.io/insight-report-prototype/

## 使用

打开演示地址，在模板库选择“占位符效果演示模板”，点击“使用模板”，提交报告要求，确认澄清大纲后生成报告。

报告生成后自动执行后置校验；在报告顶部展开“校验日志”，查看每个数据引用的数值一致性、空值检查和外键完整性记录。差异在报告原位标注，异常阻断导出，完整执行日志可展开查看。

页面内数据与智能生成结果为 Mock 演示，用于展示页面和交互；真实问数、大模型、权限与存储由开发接入。浏览器中的模板、任务及编辑内容保存在当前浏览器本地。

## 文件

- `index.html`：单文件原型，可由 GitHub Pages 直接托管。
- `.nojekyll`：使用静态文件直接发布。
- `SHA256SUMS`：发布文件校验值。
